# Power BI Analytics Portfolio

Portfólio de projetos desenvolvidos em **Power BI**, com foco em **Business Intelligence, análise de dados, indicadores e suporte à tomada de decisão**.

## Tecnologias

* Power BI
* DAX
* Power Query
* Excel
* SQL
* Data Visualization
* KPIs
* Business Intelligence

## Projetos

### 01 — Analítico de Vendas

Dashboard desenvolvido para análise de desempenho de vendas.

Arquivo:

`Analítico de Vendas.pbix`

### 02 — Marketing — Visão Cliente

Dashboard voltado para análise de dados de marketing e visão do cliente.

Arquivo:

`Projeto de Marketing Visão Cliente.pbix`

### 03 — Vendas e KPIs

Dashboard focado no acompanhamento de indicadores de vendas e KPIs de negócio.

Arquivo:

`Vendas e KPIs.pbix`

## Competências demonstradas

* Tratamento de dados
* Transformação de dados
* Construção de dashboards
* Criação de indicadores
* DAX
* Power Query
* Visualização de dados
* Análise de performance
* Business Intelligence

## Objetivo

Demonstrar a aplicação prática de Power BI na transformação de dados em **indicadores, análises e informações para suporte à decisão**.
